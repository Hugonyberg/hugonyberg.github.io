# Definition of Done

A project page or feature is considered done when:

- The page is live and accessible from the site navigation
- All described systems are implemented and have been tested in a working build
- At least one screenshot, GIF, or video demonstrates the feature in action
- The write-up clearly states what was built and which techniques were used
- No broken links or missing media assets
- The page renders correctly on desktop and mobile

A documentation file is considered done when:

- It accurately reflects the current state of the project
- It uses plain language with minimal headings
- It has been reviewed for correctness before merging
