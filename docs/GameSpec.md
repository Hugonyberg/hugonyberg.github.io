# Game Specification

## Overview

This portfolio showcases game programming projects by Hugo Nyberg, including AI systems, game design tools, and complete game projects built during studies at TGA (The Game Assembly).

## Projects

**RTS-style AI (GOAP)**
An 8-week school project featuring a Goal-Oriented Action Planner inspired by Age of Empires. A grid-based world with farmers, soldiers, and goblins controlled by GOAP-driven planning and A*-influenced movement.

**3D Enemy AI**
Enemy AI using steering behaviors (Seek, Arrival, Separation, Spread, Object Avoidance) combined with behavior trees and a shared blackboard system.

**State Machine AI**
Boss AI controlled via a state machine, demonstrating clear state transitions and reactive combat behavior.

**Navmesh Creation Tool**
Integration of the Recast Navigation library to auto-generate walkable polygon meshes from level geometry, converted into a custom grid format for pathfinding.

**Wave Manager Tool**
A game design tool for authoring and controlling waves of enemies within a game loop.

## Core Mechanics

- Grid-based world simulation
- Autonomous agent decision-making via GOAP and behavior trees
- Navmesh-based pathfinding
- Wave-based enemy spawning
- 2D collision handling with moving platforms
- Player movement and combat on a 2D grid in a 3D world
